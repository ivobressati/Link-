Preguntas frecuentes

Todo lo que necesitás saber.

¿Necesito experiencia previa para el curso Barbería Inicial? +
No. Está pensado para arrancar de cero, con una progresión clara módulo a módulo.
¿Por cuánto tiempo tengo acceso al curso? +
El acceso es de por vida. Podés volver a ver cualquier módulo cuando quieras, desde cualquier dispositivo.
¿Cómo pago si estoy fuera de Argentina? +
Ofrecemos Mercado Pago para Argentina y Stripe para pagos internacionales, con tarjeta de crédito o débito.
¿Recibo un certificado? +
Sí. Al completar el 100% de un curso, se genera automáticamente tu certificado personalizado para descargar.
¿Puedo ver las clases desde el celular? +
Sí, la plataforma está pensada primero para mobile. También podés verla desde tablet o computadora.
